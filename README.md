# VBI JAX Experiments

This repository contains my initial experiments implementing JAX-based neural mass simulations as part of GSoC 2026 preparation.

## What’s included
- Modular JAX-based structure (base, integrators, coupling, noise)
- Initial implementation of MPR (Montbrió-Pazo-Roxin) model
- Simple simulation loop using lax.scan
- Test script for running a small multi-node simulation

## Goal
To understand and prototype JAX-based simulation design aligned with VBI architecture (Issue #67).

This is an early-stage implementation and will be refined based on feedback.
